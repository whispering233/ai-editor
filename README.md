# AI Editor

![AI Editor 品牌标记](packages/client/public/brand-icon.svg)

面向小说创作者的本地优先 AI 辅助工具。**AI 是创作顾问，不是代笔**——帮助管理创作要素、探索剧情可能性、发现设定矛盾。正文（章级）在应用内用块编辑器书写、随书备份与导入导出，但 **AI 对正文只有只读权限**：能读、能评论、能建议，工具面上不存在改写入口——落笔永远由作者完成。AI 也可按需联网检索、打开外部网页核对细节（需已配置 DeepSeek 凭据），结果以可点开的来源卡片出现在对话里。

## 技术栈

| 层 | 技术选型 |
|---|---------|
| 工程 | pnpm workspace（7 包：5 发布包 + 私有 client / desktop）；Node ≥ 22.12；全仓 ESM；TypeScript strict；测试 vitest（各包独立 `test` script） |
| 服务端 | Hono 4 + `@hono/node-server`；Zod 4（仅服务端校验）；better-sqlite3 ^13（WAL，N-API 预编译）+ drizzle-orm 0.45 |
| 前端 | React 19 + Vite 7 + Zustand 5 + **antd v6**（主题 = Notion 工作区暖灰 token 覆盖）+ `@ant-design/icons` + `@ant-design/x`（Bubble/Sender/Conversations/ThoughtChain）+ `@ant-design/x-markdown`（流式）+ Tailwind 4（仅布局）+ **@blocknote/core·react·ariakit**（块编辑器，exact pin）；自制 hash 路由 |
| AI 运行时 | 嵌入 `@earendil-works/pi-coding-agent` 1.4.0（**exact pin**）：模型目录、凭据、会话文件、重试、上下文压缩、工具派发全由 pi 承担，**凡调 LLM 一律走 pi 的 Agent 路径**；本仓只提供领域工具、内核提示词与 HTTP/SSE 契约 |
| 桌面版 | Electron 44.3.0（**exact pin**）+ electron-builder；主进程内嵌 server，与 CLI 版共用同一份数据 |

## 界面与布局

视觉语言 = **Notion 工作区**一脉：暖灰纸感中性色（`#37352f` 暖炭墨 / `#f6f5f4` 外壳底 / 三层描边）、hairline 分栏、零阴影、扁平，**彩色只服务状态与标签**；组件语言只有一套 antd，排版四档 20/16/14/12。**视觉契约（单一事实源）= `docs/ui/DESIGN.md`**，纪律由 `design-discipline.test.ts` 断言。

根首页 + 一级导航 + 常驻聊天三区，可拖拽调宽 + 收起/展开（宽度与收起态、写作偏好、写作页导航栏宽度与收起、最近打开的章记 localStorage）：

- **`#/` 根首页**：按工作区类型分两区——**小说**（书籍列表：打开高亮、行尾删除；新建一本 / 导入备份 / **从云端恢复** / 打开其他路径）与**文风练习**（**预置作家卡列表**：未开始的点击即开始（懒创建）、已有数据的点击打开）；「当前工作区条」两种工作区共用（继续创作 / 导出 / 重命名 / 删除——已启用云备份时先推一份再删，可选同时删云端备份）。导出弹窗按工作区类型给项（对话文案与默认项见 `docs/ui/DESIGN.md`）
- **`#/writing` 写作页**（左栏一级导航「写作」，在「大纲」之前）：左侧卷章导航栏（卷/章结构 + `第N卷`/`第N章` + 章字数，默认 240px、可拖拽 200–480px、可左右两档收起（右侧正文列可收起为全宽 rail）、展开入口在正文页头；点章即进正文）+ 右侧正文书写面；再点「写作」回到最近打开的章（失效则回退到最近保存过正文的章）。正文面：常显写作工具条（块类型 / 格式 / 颜色 / 对齐 / 缩进 / 链接 / 撤销重做 / 保存 / 写作设置 / 专注模式）+ 铺满剩余高度的写作面；写作偏好（字体·字号·行高·纸色·纸纹理·段首缩进）记本机、所有正文共用；停止输入约 1.5s 自动保存，另有手动保存与保存时间；页头「历史」抽屉 = 章级正文历史（服务端自动快照 → 只读预览 → 恢复，恢复前会先把当前内容再存一份，可往返退回）；旧 `#/manuscript/:id` 链接自动重定向到写作页
- **`#/outline` 大纲页**：中栏左树右详情——rail 保留新建 / 改名 / 摘要 / 删除 / 拖拽 / 折叠 / 右键菜单，页头可按写作状态 / 剧情线标签筛选（未命中隐藏、全树强制展开、编号不变、不持久化），章行摘要下方显示剧情线标签（最多 2 个 + `+N`），默认 `max(320px, 中栏 1/3)`、可拖拽 280–600px、可左右两档收起（右侧详情可收起为全宽 rail）；右侧显示卷 / 章 / 场详情（基础信息 / 结构化信息 / 变更记录 / 伏笔 / 关联）。详情未保存时切换 / 清空选中 / 窄屏返回 / 新建 / 写正文先确认，浏览器后退也拦（同后退守卫哨兵）。拖拽支持空卷 / 折叠卷 / 空章 / 非空卷章整行落为子级。
- **`#/canvas` 大纲画布**（一级导航「大纲画布」，排在「大纲」之后，仅小说工作区）：把章摊成卡片网格（`第N章` + 章名 + 状态与剧情线标签；没有状态与标签的卡自动矮一档，不留空行），每行 5 张、首屏按内容算落点（装得下居中、装不下从左上角起步，不再把首屏缩成 0.5 的不可读小字），缩到 0.72 以下切 far 档：26px 大章名 + 左上角章号数字（只显示 n，不显示第/章；第N章徽标 / 标签隐藏，悬停仍可看全）；左上工具条 = 筛选（卷 / 状态 / 剧情线三维叠加，未命中卡片淡化不重排）+ 缩放；画布只渲染视口内的卡片，千章书也不一次挂满；章与章之间拖出 `plot_edge` 连线（带方向箭头，短标签显示在线上），拖动只改摆位（按书存本机，不进项目文件 / 备份 / 云端），单击卡片聚焦邻边、双击跳大纲节点——结构与顺序仍只在大纲树改
- **`#/setting` 设定页**：中栏左树右详情——rail 保留新建 / 改名 / 描述 / 拖拽 / 排序 / 搜索与标签过滤 / 删除 / 右键菜单，默认 `max(320px, 中栏 1/2)`、可拖拽 280–720px、可左右两档收起（右侧详情可收起为全宽 rail）；右侧是设定详情（单列）；选中唯一来源 = URL，详情未保存时切换 / 清空选中 / 新建 / 窄屏返回 / 收起详情先确认；窄屏退化为树与详情两级互斥
- **子栏面板开关**：写作 / 大纲 / 设定三页的左右栏收起 / 展开钮固定在内容区左右外端——左钮在左栏页头（左栏收起后移到右列页头），右钮在右列页头动作组末尾（该列收起后移回左栏页头）；点击只换父容器、不移动，单栏时只保留有效钮
- **左栏**：品牌标记 + 顶部标识（小说 = `书架`、练习 = `文风练习`，点击回根首页）+ **按工作区类型渲染的一级导航**（项集与落点见 `docs/ui/DESIGN.md` §导航与外壳）+ 设置 / 主题切换
- **中栏**：工具栏（左右栏收起/展开（同 `Ctrl/Cmd+B` / `Ctrl/Cmd+Shift+B`）、全局刷新、窄屏聊天开关；不承载项目名 / 阅读进度 / 语言）+ 页面内容区 + 右下悬浮「问 AI」（带当前页面上下文注入右栏）
- **右栏**：AI 聊天常驻（会话随项目目录走、窄屏折叠为抽屉；x `Conversations` 会话列表 + x Bubble / x-markdown 消息流（一条消息内顺序 = 思维链 → 工具调用行 → 正文 → 历史提案只读卡）+ 提案组卡（live；支持批量确认 / 拒绝与自动确认）；**生成中可一键停止**（与断连同一条取消链路，已生成的部分保留）；输入框下方 = 配置行（模型 / 思考强度 / 自动确认）+ **会话状态栏**（上下文占用 · 费用 · 解码速度 · 缓存命中率 · 累计 tokens；只读、窄栏按优先级隐藏，见 `docs/ui/DESIGN.md`））
- **三栏默认宽度**：左 10% / 右 40% / 中栏吸收剩余（1:5:4 在 1600–2400 视口精确成立）

## 包结构

```
shared → db → tools → agent → server    （依赖方向；client 只依赖 shared，desktop 只依赖 server）
```

`shared`（类型 / 常量 / API 契约，浏览器安全）· `db`（SQLite 建表 / 查询 / 原子写 / 增量迁移）· `tools`（领域工具，TypeBox schema）· `agent`（pi 运行时装配、内核提示词、会话事件投影）· `server`（Hono API + SPA 静态托管）· `client`（React SPA）· `ai-editor-desktop`（Electron 外壳，不含业务逻辑）。

## 桌面版（安装包）

装完双击即用（**不需要 Node / npm**）；**当前只提供 Windows 安装包**（macOS / Linux 等有真实用户需求再做）：

| 平台 | 安装包 | 首次打开注意 |
|---|---|---|
| Windows | `AI-Editor-<版本>-win-x64.exe`（NSIS） | 未签名 → 可能弹 SmartScreen，选「仍要运行」 |

- 安装包挂在对应版本的 GitHub Release；首次启动**零交互**用 `<文档>/AI Editor` 作书库，可在 设置 → 通用 → 书库位置 更改（路径不可用时逐级回退 `<主目录>/AI Editor` → `<userData>/AI Editor`）；与 CLI 版**共用同一份数据与凭据**（同一份 pi 配置目录、项目目录格式一致），两边可打开同一个书库
- **pi 配置目录默认 `~/.ai-editor/pi-agent/`**（与 pi CLI 的 `~/.pi/agent` 隔离，互不覆盖）：模型凭据 / 模型覆盖 / 运行参数都在这里，可在 设置 → 高级 改目录，或用表单改联网搜索凭据 / 自定义模型 / 运行参数（四份文件的 JSON 编辑器仍保留为兜底）；升级到本版本后需重新配置一次 API key（或把目录指回 `~/.pi/agent`）
- **自动更新（仅 Windows 安装态）**：启动后自动检查 GitHub Releases，下载完由你决定何时重启安装（菜单 → 帮助 → 检查更新…）；只替换程序文件、不动书库。⚠ **首个带更新能力的版本需手动下载安装一次**
- **界面缩放**：`Ctrl/Cmd + =` / `Ctrl/Cmd + -` / `Ctrl/Cmd + 0`、菜单「视图」或 设置 → 通用 → 界面缩放 在 80%–200% 的八档之间缩放整个界面（Electron 页面缩放，与浏览器缩放同语义）；后两处都显示当前百分比，每次改档另弹一条短提示（连按只升级同一条）。选择记在本机 `desktop.json`，重启与换书库都保留；浏览器形态不接管这组键、也不渲染这张卡（浏览器原生缩放已覆盖）
- 本地出包 `pnpm desktop:dist`（产物在 `packages/desktop/release/`；**Windows 包由 CI 出**）；与 npm 包共用同一个 tag

## 快速开始

**用户安装（CLI）**：`npm install -g @whispering233/ai-editor-server` → `ai-editor <项目目录>`（启动服务并打开浏览器 `http://127.0.0.1:3500`，web 生产分段起点；被占时在分段内 +1，实际端口以启动日志/打开的地址为准）；发布链路与 npmjs 一次性前置见 `docs/design/build.md`。

```bash
pnpm install
pnpm -r build              # 按依赖序构建 7 包
pnpm dev                   # 开发态：client :5173 + server :3520（dev 分段起点，proxy /api）
pnpm start:test-project    # 测试项目（数据落 test-project/books/ 与 practice/，该目录整体不入库）
pnpm typecheck && pnpm lint && pnpm -r test   # 验证
```

运行、构建、打包与发布链路见 `docs/design/build.md`；服务端调试日志（创作根 `.ai-editor/config.json` 四类别 chat / request / usage / http，无配置文件即全关）见 `docs/design/config.md`。

## 当前能力（逐版本变更历史见根 `CHANGELOG.md`）

- **项目管理**：书架模式（创作根下按工作区类型分目录：小说 = `books/`、练习 = `practice/`）、创建 / 打开 / 关闭 / 重命名 / 删除、项目规则文件 `AGENTS.md`（取代 project.json `prompt`，支持外部编辑检测；存在时随备份 / 导出 / 云端包搬运，恢复按包内镜像）；备份包/导入/云端导入按包内 `kind` 落回对应目录
- **大纲**：卷→章→场景三层（章只能挂卷）增删改移 + 拖拽 / 行内编辑 / 右键菜单；**中栏左树右详情**（rail 可拖宽 / 左右两档收起，详情未保存守卫——包括浏览器后退；空卷 / 折叠卷 / 空章 / 非空卷章均可拖入）；卷章自动编号（`第N卷` / `第N章`，纯展示：只计未软删节点，删后重排）；节点详情含麦基《故事》结构化字段；章另带工作面四字段（状态 / 剧情线标签 / 叙事功能 / 张力度）——状态与标签在大纲树章行和画布卡片上显示，画布还可按两者筛选
- **剧情推演**：在大纲树上把若干**章**标为**推演节点**（`project.json` 的 `deduction_nodes`，随书备份/云端/恢复；单标记 = 开放式发散，多标记 = 相邻标记之间的剧情线探讨）——大纲树行与节点详情页显示派生徽标（`推演节点` / `推演起点` / `推演节点 k` / `推演终点`）；悬浮「问 AI」把标记集合注入上下文，AI 也可自行调 `get_deduction_marks` 取标记与相邻区间骨架；大纲页页头可**一键清除全部标记**（有可见标记时才出现）；**标记是作者意图，AI 只能读、不能改**；`#/canvas` 画布页把章摊成卡片网格，章与章的关系用 `plot_edge`（拖出即连，标签在线上、说明在抽屉）
- **正文**：章级块文档编辑器（标题 / 列表 / 引用 / 代码 / 表格 / 图片），自动保存（**输入即显示「编辑中…」，停手约 1.5s 落盘转「已保存 · HH:MM」；桌面版关窗 / 退出前会先落盘**）+ 手动保存 / `Ctrl/Cmd+S` 即时显示「已保存」+ 冲突提示；导入块 JSON / Markdown，导出块 JSON（无损）、Markdown（有损）与纯文本 TXT（整本 / 单章；可选保真 / 网文排版，不可再导入）
- **码字统计**：小说维度按天累计章正文正增量（删除不扣、不回溯）；`#/stats` 统计页提供今日 / 本月 / 累计 / 码字天数、月历、近一年绿色热力与多时间窗柱状趋势；正文页「问 AI」上方有可拖动的当日悬浮面板（本次码字 / 速率 / 码字时间 / 空闲时间），位置记本机、会话数字不落库。日统计在 `data.db`，随备份 / 云端 / 恢复继承。另有**每日目标**（本机偏好、按书隔离）：统计页「今日目标」卡与写作页卷章栏页头常显今日进度与连续天数，达标只做内联变色，不弹窗。
- **实体与关系**：七类实体（人物 / 设定 / 地点 / 伏笔 / 事件·时间轴 / 时间标签点·时间轴 / 参考资料）CRUD、k 跳关系遍历、设定层级（`belongs_to` 防环）与树形视图、标签分类与筛选、Delta 变更追踪与 `computeState`（章序前缀累积）；关联总览支持按源 / 目标端点类型分别筛选（AND）；关系可带短标签 / 说明（`metadata.label` / `description`，画布连线上显示标签），建关系时的类型选单与 AI 提案按所选两端的端点适用性收窄（服务端不新增校验，自定义类型不受影响）
- **人物页**：master-detail 工作台——人物档案（可编辑）/ 阅读进度（只读）/ 人物关系网 / 其他关联四个平级 tab；能力面板 = 用户自定义字段树；**角色优先级**（主角 / 主要配角 / 配角 / 龙套，未分级沉底）驱动左栏默认排序
- **时间轴**：时间标签点与事件双实体（`occurs_at` 挂载、独立线性序、拖拽重排与跨组改挂）、`occurs_in` 锚定大纲场景（倒叙 / 多时间线可表达）
- **伏笔**：伏笔池面板（活跃 / 已回收 / 已废弃、推进 / 回收 / 废弃复合写确认、依赖链展开）+ 大纲节点伏笔标记（大纲树行内，点击跳该伏笔详情）+
  「已写未回收」提醒（预计回收的那章已经写了正文、伏笔却没回收：伏笔页行标记 + 只看筛选，写作页卷章导航栏显示计数）
- **参考资料**：第 7 类实体（`ref-` 前缀），表格列表 + 块编辑器正文 + 分类 / 标签 / URL；Markdown 与块 JSON 导入导出
- **数据备份**：一键导出完整项目 zip（或导出**小说文档**：卷/章 markdown 目录树 zip，内联样式有损、**不可再导入**；或导出**纯文本 TXT**：整本单文件、保真 / 网文排版、UTF-8，不可再导入）/ 从备份导入；自动备份（可调频率，有变更才备份，自动保留最近若干份，档位与份数上限取 shared 常量）+ 手动备份（可带名称）+ 备份重命名 + 加载备份（覆盖前自动快照）+ **`Ctrl/Cmd + S`** 快捷存档（任意页面 = 保存当前内容并生成本地存档；键位清单见 设置 → 快捷键）；**云端存档（WebDAV）**把备份 zip 同步到用户自己的云盘做异地副本与多设备续写（本地仍是唯一事实源；新机器可用「从云端恢复」拉回整本书；自动推送随自动备份频率触发，频率关闭即不推送、设置页会提示）；软删内容走**回收站**（还原 / 彻底清除 + 启动一致性校验）。**备份/项目包导出/云端的包 = 三文件 + 可选项目规则（`AGENTS.md`）**：对话历史 `sessions/` 是纯本地目录（不进包、不跨机器搬运、恢复类操作不碰它；小说文档 / 纯文本导出同样不含它，且只含正文）
- **AI 对话**：可按章正文 / 参考资料正文（`body`）/ 大纲结构（状态、标签、卷）检索定位，不必逐章通读；工具集按工作区类型收窄（结构性边界：练习工作区不注册小说工具与提案工具）；**清单与计数单一来源 = `docs/api/tool-calling.md`**，不在此复述数字；联网检索结果按默认 / 上限条数与单条摘要异常上限收敛，全文走 `fetch_content`；提案组卡 + 批量确认 / 拒绝 + 自动确认（YOLO，默认关）+ 历史只读回看（从会话 `toolCalls` 重建，不持久化状态）；live 提案 TTL 10 分钟 + 快照重校验；SSE = pi 会话事件投影；思维链默认折叠；**AI 只提案不写入**，正文与参考资料只有只读工具
- **作家文风练习**（独立工作区 `kind = practice`，**一位预置作家 = 一个工作区**，数据与小说完全分开）：作家介绍 / 作品介绍 / 作家风格说明三面预置素材（**不预置作品正文**；风格说明可自己改 / 用 `.md` 替换 / 恢复预置），**文风练习**（导入或粘贴范文挂到作品下 → 写我的稿（纯文本）→ 「让 AI 点评」→ 结构化**点评卡**：维度 / 依据特征 / 你的写法 / 引用 / 建议，引用必须是依据或稿件原文的子串），**自由练习**（自拟或让 AI 出题（题目 + 写作要求）→ 写稿 → 按风格说明点评）；工具面**没有任何能写用户稿件的工具**
- **AI 设置**：模型目录与凭据全部来自 pi（设置页只列已配置 provider；key 写入 pi agent dir，不入项目文件）；联网搜索凭据、自定义模型 provider / 模型行、重试 / 压缩 / 出站空闲超时可在 设置 → 高级 的对应表单里改（本机级，不入项目文件；JSON 编辑器保留为兜底，`models.json` 写入前自动留一份 `models.json.bak`）；出站请求支持 HTTP 代理（读 pi 全局设置的 `httpProxy`，未设时回落环境变量）

## 设计原则

- **本地优先**：数据全存本地（project.json + outline.json + data.db + sessions/），本地是唯一事实源；云端存档只是备份的另一块磁盘，随时可停用（对话历史为纯本地目录，不进备份/导出/云端）
- **工作区抽象**：创作根下的顶层单位是**工作区**（`kind`：小说 / 文风练习）——异质场景用**独立工作区 + 专属表**，共用同一套持久化管道（备份 / 云端 / 会话 / 恢复 / 原子写）；**AI 能力面按工作区类型收窄**（练习工作区不注册小说工具与提案工具，是结构性边界）
- **结构体先行**：创作要素结构化（人物 / 设定 / 地点 / 伏笔），AI 在结构上做语义分析与建议
- **AI 只提案不写入**：结构化数据写操作一律走「提案确认」；正文与参考资料 AI 只有只读工具
- **软删 + 回收站**：误删可还原，purge 才物理清除
- **不做超长正文生成 / 不做批量拆解导入**：超长文本无论怎么工程优化都绕不开上下文窗口爆满、腐化与漂移，这类产出物可信度无法自证；AI 只在作者已有结构上分析与建议（正文仍只读），要素由作者录入或导入备份
