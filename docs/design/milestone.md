**v0.0.27（2026-09-10）——用户反馈七项**——实体列表页去残留（「实体」标题 + 类型 Segmented tab，类型切换归左栏 NavRail）；面包屑整站移除（`Breadcrumb` 组件删除 + 4 详情页，一级化后层级结构失效，返回走 NavRail）；「问 AI」入口迁中栏右下悬浮按钮（antd `FloatButton`，InfoBar 移除）；focus 小条显示实体名称（`names/resolve`，替代裸 entity id）；「新建即聚焦」泛化（设定树/实体列表/大纲/时间点：滚动 + 高亮 + 键盘焦点）；`Ctrl/Cmd+S` 保存快捷键（注册栈，覆盖 4 详情页表单 + 伏笔编辑态 + 5 处行内编辑）；设定树拖拽插入线强化；「问 AI」点击必有反应（右栏收起/小屏抽屉自动打开 + 无项目/未选中条目中性提示）；死代码 `hooks/use-api.ts` 清理。**API/数据契约零改动**（纯前端交互层）。

**v0.0.29（2026-09-11）——用户反馈九项 + 两条 antd v6 静默失效根因**——探查用户报的「颜色单调/图标按钮不统一/标签不突出/拖拽无插入线/气泡看不清」时摸到两条「测试全绿但像素全错」的根因：① **cssVar 的 `--ant-*` 从不注入 `:root`**（挂在组件级 class 作用域）→ `index.css` 的语义变量映射整体解析为空，全站 Tailwind 语义色静默透明（v0.0.26 引入、v0.0.28 未被发现；修法 = `cssVar.key` 与 `index.html` 的 `<html class>` 同值，守卫 `cssvar-scope`）；② **Button 的 `variant` 必须与 `color` 同时给**（22 处 `variant="text"` 实为带边框 outlined，守卫 `button-variant-color`）；另修 user 气泡 `colorPrimaryBg`（深墨 seed 派生 `#787771`，对比度 1.9:1，守卫 `primary-bg-token`）。新增**标签 tint 系统**（`--tag-*` 六色 + FNV-1a 名称 hash「同名恒同色」+ `ui/tag-chip.tsx` 唯一实现，替换 9 处 chip）、**中栏页面头部统一结构**（标题单独一行 + 控件行「左筛选右操作」+ 搜索框统一规格，重排 7 页）、**拖拽指示线统一**（`ui/drop-indicator.tsx`）、**按钮统一**（自绘图标按钮全部收敛 antd + `danger` 语义）、守卫规则 4→13 条（含 `no-dynamic-class`）。**API/数据契约零改动**。

**v0.0.29（2026-09-11）——链式新建断链**（用户反馈）——设定页「新建→回车→再回车建子设定」做不到：就地新建提交后新条目只拿到焦点与临时高亮、**未进入选中态**，而「Enter 新建子级」的守卫要求选中该行 → 第二次 Enter 被静默吞掉（toast 不抢焦点，只是同时出现造成「被提示打断」的错觉）。修法：新条目进入「选中 + 聚焦」双态；设定树的选中态必须放在「新行已渲染且聚焦成功」的效应里（`reload()` 是异步链路，提前设会被「选中失效清理」效应按旧树误判清零——实测踩坑）。契约入 `layout.md §7「链式新建」`。
