# UI 总体布局设计（layout）

> 定位：**总体布局与交互结构**——工作台外壳、路由、各栏内容结构、交互红线（批次十七起：前端基座 = antd v6 + @ant-design/x，样式实现归代码 `client/`，本文档不承载 CSS 细节，禁止以本文档为样式依据回写样式）。

---

## 1. 布局总览（导航栏 + 工作台两栏）

```
┌────────────────────┬──────────────────────────────────────┬────────────────────┐
│ 左栏 NavRail（窄）   │ 中栏 (50%)                            │ 右栏 (40%)          │
│                    │ ┌────────────────────────────────────┐ │                    │
│ 产品标识            │ │ 信息条：项目名 | 当前位置 | 语言       │ │ 会话标题（下拉切换）   │
│ [⇱ 书架·当前书名]    │ ├────────────────────────────────────┤ │ [+ 新会话]          │
│ ────────────────  │ │                                    │ │ ────────────────── │
│ 概览               │ │             页面内容区（按路由渲染）    │ │ 消息流              │
│ 大纲               │ │                                    │ │  （user 气泡 /      │
│ 人物               │ │                                    │ │   assistant 排版）   │
│ 设定               │ │                                    │ │  [🔧 工具折叠行]      │
│ 地点               │ │                                    │ │  [提案卡]           │
│ 伏笔               │ │                                    │ │ ────────────────── │
│ 时间轴             │ │                                    │ │ 正在讨论：…（focus）  │
│ 关联               │ │                                    │ │ 输入区      [发送]   │
│ 参考资料           │ │                                    │ │                    │
│ ────────────────  │ │                                    │ │                    │
│ 回收站（工具区）     │ │                                    │ │                    │
│ ────────────────  │ │                                    │ │                    │
│ 设置 / 主题切换     │ └────────────────────────────────────┘ │                    │
└────────────────────┴──────────────────────────────────────┴────────────────────┘
```

- **结构**：书架主页 `#/` 之外，工作台 = 左栏导航 + 中栏 + 右栏三区；中/右可**拖拽调宽 + 收起/展开**（中栏保底宽度、不可完全收起；实现优先 antd Splitter，能力缺口则保留 use-panels 语义，仅换肤），宽度与收起态持久化 localStorage（纯展示偏好，不进数据文件）。
- **<1024px**：不渲染拖拽手柄/收起按钮，回退默认比例；右栏 ChatPanel 折叠为抽屉（开关在信息条右侧，仅小屏出现）。
- 中栏内容区纵向滚动；各栏为 `min-h-0` flex 子容器（防溢出，实现细节归代码）。
- **无二级 tab**：全站页面组织只有一级（左栏导航项）+ 页面内详情覆盖（详情路由不新增 tab，见 §2）。

### 各栏职责

| 栏 | 内容 |
|----|------|
| 左栏 NavRail | 产品标识；**回到书架按钮**（旁显当前书名，点击回 `#/` 书架主页——频繁切书场景少，书架树不做常驻栏）；垂直导航九项（见 §1.1 顺序）；分隔工具区（回收站）；底部设置入口 + 主题切换。无项目打开时：不显书架按钮/书名，导航项禁用态引导回书架 |
| 中栏 MainPanel | 信息条 + 页面内容区（按路由渲染）；**无 TabBar**（中栏 tab 已并入左栏导航） |
| 右栏 ChatPanel | AI 聊天常驻；**会话归属项目**（随项目切换清空并重载）；无项目打开时整体禁用（提示「打开项目后可用」） |

### 1.1 左栏导航项与顺序（唯一事实源）

导航（自上而下）＝ 概览 → 大纲 → 人物 → 设定 → 地点 → 伏笔 → 时间轴 → 关联 → 参考资料；回收站属「工具区」（分隔线下）；设置/主题在栏底。此顺序任何调整只动左栏组件与 §2 高亮规则，**不触碰 API 契约**（前端页面组织与后端 API 完全解耦——API 按数据对象类型划分，见 architecture.md）。

## 2. 路由结构（hash 路由，自制 `useHashRoute`）

路由首段与左栏导航一一对应（列表与详情路由下导航保持高亮——高亮按 §2.1 前缀规则）：

| hash | 页面 | 左栏导航 |
|------|------|---------|
| `#/` | 书架主页（默认落地；无项目引导形态也在本页，见 §4） | —（顶部书架按钮） |
| `#/overview` | 项目概览（原 Dashboard 概览形态；打开书后落地） | 概览 |
| `#/outline`、`#/outline/:nodeId` | Outline / OutlineDetail | 大纲 |
| `#/characters`、`#/characters/:id` | 人物列表 / 详情 | 人物 |
| `#/setting`、`#/setting/:id` | 设定（树形视图）/ 详情 | 设定 |
| `#/locations`、`#/locations/:id` | 地点列表 / 详情 | 地点 |
| `#/hooks` | 伏笔富页（依赖/状态） | 伏笔 |
| `#/timeline`、`#/timeline/:id` | 时间轴 / 事件详情 | 时间轴 |
| `#/relations` | 关系总览 / 剧情连线 | 关联 |
| `#/references`、`#/references/:id` | 参考资料 / 详情 | 参考资料 |
| `#/trash` | 回收站 | 回收站（工具区） |
| `#/preferences` | 设置 | 左栏底部入口 |

- 路由解析按段数：列表/富页 = 首段；详情 = 2 段（id 段）。未知首段回退 `#/`。
- **旧址重定向（批次十七路由一级化）**：`#/entities/character[/:id]` → `#/characters[/:id]`；`#/entities/setting[/:id]` → `#/setting[/:id]`（含 `setting-tree`）；`#/entities/location[/:id]` → `#/locations[/:id]`；`#/entities/relations` → `#/relations`；`#/entities/hook` → `#/hooks`；`#/entities/event[/:id]` → `#/timeline[/:id]`；`#/entities/timepoint[/:id]` → `#/timeline`；`#/entities/reference[/:id]` → `#/references[/:id]`；`#/settings` → `#/preferences`。重定向仅前端路由层（hash 不出浏览器），服务端零感知。
- 泛型列表入口去重原则（批次十二 T3 先例延续）：某实体类型已有专属富页（伏笔/时间轴/参考资料）时，不设独立泛型列表导航；数据能力端点保留不变（UI 无入口 ≠ API 可删）。

### 2.1 导航高亮规则

- 常规项：首段前缀匹配（如 `outline`、`hooks`、`timeline`…含各自详情路由）；
- 「人物/设定/地点/关联」同属实体家族但各自独立高亮：匹配 `characters`/`setting`/`locations`/`relations` 首段（一级化后各类型路由为独立首段，无需两级匹配；此规则若路由再变随之更新）；
- 书架按钮高亮：仅当 `#/`。

## 3. 中栏结构

- **信息条**（自左向右）：项目名（加载中「加载中…」；无项目显示「书架」；**点击回 `#/` 书架**）|「当前位置: 标题」（null → 未设置；点击跳 `#/outline` 并定位该节点）|「语言: {language}」| 聊天开关（仅 <1024px）。
- **内容区**：按路由渲染；页面由「数据编排 + 区块」构成（区块 = 标题 + 内容；区块失败不阻塞其他区块，带重试）。
- **页面头部统一结构（列表/富页，概览与回收站除外）**：两行——**第一行 = 页面标题单独一行**（`PageTitle`，每页一个）；**第二行 = 控件行**：左侧依序「搜索框 → 分类 → 标签 → 排序」（该项不存在就不占位；**搜索框恒在最左**），右侧「操作按钮」（靠右对齐，`ml-auto`）。
  - 有内容级筛选的页：人物/地点（搜索 + 排序）、设定树（搜索 + 标签 + 排序 + 全部展开/折叠）、关联（端点类型 + 关系类型 + 搜索 + 建立关联）、时间轴（标签筛选 + AI 排序/新建事件/新建时间点）、参考资料（搜索 + 分类 + 标签 + 3 个新建入口）。无筛选的页（大纲、伏笔）保留第二行但左侧为空（保持跨页头部节奏一致）。
  - 搜索框全站统一规格（`DESIGN.md` §Components `search-input`）：`SearchOutlined` 前缀 + 固定 192px 宽 + `allowClear`；**位置一律在控件行最左**（不再有些页右对齐）。
  - **详情页不适用本结构**（人物/大纲/参考资料/时间轴事件详情等）：保持「标题 + 保存/删除」形态（非列表页，无筛选语义）。
- **右下悬浮「问 AI」按钮**：常驻中栏内容区右下角（`<1024px` 同样悬浮于中栏之上）；点击 = 读 ui store 当前页面焦点写入 chat store focusContext（对应 POST /chat 请求体 `context` 字段）+ 聚焦右栏输入框；无页面焦点时点击 = 普通进入聊天（focus 小条不出现）。**点击必有反应**：右栏收起（桌面）/小屏聊天抽屉关闭时先展开/打开再聚焦输入框；无项目打开时不置禁用（disabled 会吞掉点击与 tooltip）而是中性轻提示「打开项目后可用」；无页面焦点（未选中具体条目）且右栏本就可见时补中性轻提示「未选中具体条目，可直接在右栏提问」（聚焦输入框的变化过于隐形）。信息条不承载此入口。
- **实体列表页不带类型 tab**：人物/设定/地点/关联为独立一级导航项，切类型走左栏 NavRail（批次十七一级化后残留的类型 Segmented 已移除）；列表页自身只保留搜索/排序/新建等内容级控件。
- **无项目**：导航禁用引导回书架；右栏 ChatPanel 整体禁用。

## 4. 书架主页（`#/`，即「主页」）

- **引导形态**（无项目/无书）：「还没有书，先创建一本」+ 新建表单 + 「打开其他路径…」+ 导入入口。
- **书架形态**：书卡片/行列表（封面、书名、最近活动；**当前打开书高亮**「打开/继续」）；行级操作按钮直接展示（导出、重命名——红线：不收 `⋯` 菜单）；新建项目 / 导入备份 / 打开其他路径入口。
- 打开书 → 跳 `#/overview`（概览）。会话切换不进书架（由右栏会话下拉承担）。

## 5. 概览页（`#/overview`）

「项目概览」：创作要素计数四卡、大纲概览、最近会话（形态沿原 Dashboard 概览形态）。

## 6. 右栏 ChatPanel 结构（自上而下）

1. **会话标题行**：当前会话下拉切换（列出本项目会话：摘要 + 条数 + 相对时间；无历史提示；刷新/打开项目自动激活最近会话）+ 新会话按钮。
2. **断连横幅 / 错误条**：横幅「上次会话已取消」+ 重新发送 + 关闭；错误条 = 图标 + 文案 + 关闭。
3. **消息流**：user 消息气泡；assistant 消息流式渲染（`@ant-design/x-markdown`：增量渲染——已完成消息 memo 缓存，仅流式尾块重渲）；工具调用行 = 折叠 + 状态（进行中/成功 ✓ / 失败 ✗，展开见参数摘要——id 解析为名称）；提案卡（类型中文标题 + preview 摘要 + 确认/拒绝；已确认/已拒绝/失效三态，失效后按钮禁用）。历史消息工具调用以「渲染层双形态归一」处理（wire `function.name/arguments` 与内部形态并存兼容，存储形态不动）。
4. **focus 小条**：「正在讨论：{类型} {名称}」+ 关闭；名称经 `names/resolve` 解析（解析中占位、失败才退 id）；来自中栏右下「问 AI」悬浮按钮 / 右键菜单注入。
5. **输入区**：多行输入（Enter 发送 / Shift+Enter 换行，组合输入法不触发）；streaming 期间禁用 +「AI 思考中…」。

## 7. 交互红线（跨页通用约定，antd 基座下生效）

- **操作按钮禁止收进 `⋯`/更多菜单**：所有操作按钮一律直接展示；下拉/选择器仅保留「会话选择」等选择器场景，不作为操作按钮容器。**右键菜单例外**（需要时出现的上下文交互）。
- **确认对话框**：不可恢复操作（purge、物理删关系）必须二次确认并说明影响范围；软删与回收站还原直接执行，不弹确认。
- **软删成功**：跳回列表/大纲页 + 轻提示「已移入回收站，可随时还原」。
- **带上下文进聊天（不跳页）**：中栏右下「问 AI」悬浮按钮或右键菜单 → 写入 chat store focusContext（对应 POST /chat 请求体 `context` 字段）→ 右栏显示 focus 小条；MainPanel 路由切换时清空 focus 上报。
- **详情页不设面包屑**：批次十七一级化后原「实体 › 类型 › 名称」结构失效，整站移除 Breadcrumb（组件已删）；详情页返回靠左栏 NavRail（列表/富页导航项高亮保持），页内不重复提供层级导航。
- **新建即聚焦**：新建成功后视图滚动到新条目 + 临时高亮 + 键盘焦点落在新条目（就地新建表面：大纲节点 / 设定树 / 实体列表行内新建 / 时间轴时间点）；新条目不在当前视图（排序/分页/筛选/上限截断）时静默跳过，不强行跳页。**临时高亮用 primary 10% 淡染面 + 1px primary 30% 描边（与选中态同一语言）**——近白的 `surface-muted` 在白底上不可见，禁用（`.dark` 下同理）。
- **拖拽落点反馈（全站统一）**：被拖行 `opacity-50`；**合法落点必给可见反馈**——同级插入位 = primary 实线插入线（3px + 两端圆点），「成为子级」位 = 目标行 primary 淡染面 + 描边；**非法落点（防环/自指/非当前排序模式的重排）一律无反馈**（无线无高亮 = 不可放）。插入线的位置就是**落点语义的图示**（线上方 = 插到该行之前，线下方 = 之后，行面高亮 = 成为其子级）。设定树的同级重排仅在「手动排序」模式开放（其余模式无 `order` 语义，拖拽只能调层级）。
- **保存快捷键**：`Ctrl/Cmd + S` 触发当前页面保存——表单页 = 保存按钮同动作；行内编辑进行中 = 提交当前编辑（Enter 同语义）；拦截浏览器默认保存对话框；无保存语义时按下不响应。
- **行级交互模式**（树/组 + 行结构页面统一心智，行级操作按钮收敛为只保留删除）：双击行 = 跳详情；单击标题 = 行内编辑（Enter 确认、Esc 取消、失焦保存）；选中节点 Enter = 就地新建子级；行级只保留删除按钮；拖拽排序/移动保留（层级约束与防环校验沿用各页语义）。
- **图标按钮只有一种实现**（视觉契约见 `DESIGN.md` §Components `icon-button`）：antd `Button color="default" variant="text" size="small"` + `@ant-design/icons`；自绘 `<button>` 图标按钮不再新增（历史混用导致灰/墨/红三套并存）。不可恢复操作（purge、物理删关系）用 `danger` 红，软删保持常规色。
- **右键菜单**（大纲节点/实体/伏笔/参考资料/时间点/事件行）：菜单项 = 「注入会话上下文」+「建立关联」（新建 relation_records 关联，端点按行实体类型预填）。
- **主题切换**：左栏底部按钮，浅/深双主题 = antd ConfigProvider 双算法（lightAlgorithm/darkAlgorithm）；色值不取 antd 默认色板，而是 Notion 工作区的暖灰 token 覆盖（值见 `DESIGN.md` §Colors，改色唯一入口 = `AntdProvider.tsx`）；切换态持久化 localStorage，首帧 FOUC 防护保留（深色模式首帧不闪白）。
- **样式纪律**：颜色一律经 antd token（组件 props/token 或 cssinjs 变量），**禁止硬编码色值/色类**；布局结构允许 Tailwind utility（不含颜色）。**视觉契约的单一事实源 = `docs/ui/DESIGN.md`**（颜色/字体/四档字号/圆角/间距/组件外观 + antd seed 与组件 token 覆盖表）——本文档不重复样式细节，改样式先改 DESIGN.md 再改代码。
