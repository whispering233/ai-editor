# UI 总体布局设计（layout）

> 定位：**总体布局与交互结构**——三栏工作台外壳、路由、各栏内容结构、交互红线。样式实现细节归代码（`client/src/index.css` 主题 tokens + 组件类，视觉实现即事实源），本文档不承载任何 CSS 样式约定；禁止以本文档为样式依据回写样式细节。

---

## 1. 布局总览（三栏工作台）

```
┌───────────────┬──────────────────────────────────────────────┬──────────────────────┐
│ 左栏 (10%)     │ 中栏 (50%)                                    │ 右栏 (40%)            │
│               │ ┌────────────────────────────────────────────┐ │                      │
│ 产品标识        │ │ 信息条：项目名 | 当前位置 | 语言 | (聊天开关) │ │ 会话标题（下拉切换）    │
│               │ ├────────────────────────────────────────────┤ │  [+ 新会话]          │
│ 书架           │ │ TabBar：概览|大纲|实体关系|伏笔|时间轴|      │ │ ─────────────────── │
│  ▸ 项目行       │ │         参考资料|回收站                     │ │ [⚠ 上次会话已取消]     │
│    ▸ 会话行     │ ├────────────────────────────────────────────┤ │ 消息流               │
│  [+ 新建项目]   │ │                                            │ │  （user 气泡 /        │
│  [+ 导入备份]   │ │             页面内容区（按路由渲染）          │ │   assistant 纯排版）  │
│               │ │                                            │ │  [🔧 工具折叠行]       │
│  ───────────  │ │                                            │ │  [提案卡]             │
│  设置          │ │                                            │ │ ───────────────────  │
│  主题切换      │ └────────────────────────────────────────────┘ │ 正在讨论：…（focus）   │
└───────────────┴──────────────────────────────────────────────┘ 输入区        [发送]  │
```

- **默认比例 1:5:4**（左 10% / 中 50% / 右 40%）；三栏可**拖拽调宽（像素）+ 收起/展开**（中栏不可完全收起，保底宽度）；宽度与收起态持久化 localStorage（纯展示偏好，不进数据文件）。
- **<1024px**：不渲染拖拽手柄/收起按钮，三栏回退默认比例；右栏 ChatPanel 折叠为抽屉（开关在信息条右侧，仅小屏出现），桌面态开关不渲染。
- 中栏内容区纵向滚动；三栏为 `min-h-0` flex 子容器（防溢出，外壳实现细节归代码）。

### 三栏职责

| 栏 | 内容 |
|----|------|
| 左栏 `Sidebar` | 产品标识（点击回 `#/`）、书架（项目→会话二级树，单展开：同一时刻只展开一本）、新建项目、导入备份、行级导出/重命名（仅当前打开项目行）、底部设置入口 + 主题切换 |
| 中栏 `MainPanel` | 信息条 + TabBar（7 tab）+ 页面内容区（按路由渲染） |
| 右栏 `ChatPanel` | AI 聊天常驻；**会话归属项目**（随项目切换清空并重载）；无项目打开时整体禁用（提示「打开项目后可用」） |

## 2. 路由结构（hash 路由）

自制 `useHashRoute`，不引入 React Router。路由首段与中栏 tab 一一对应（「实体关系」tab 在实体列表/详情路由下均保持高亮）：

| hash | 页面 | 中栏 tab |
|------|------|---------|
| `#/` | Dashboard（默认落地；无项目时为引导形态） | 概览 |
| `#/outline`、`#/outline/:nodeId`（节点详情） | Outline / OutlineDetail | 大纲 |
| `#/entities/:type?`、`#/entities/:type/:id` | EntityList / EntityDetail | 实体关系 |
| `#/hooks` | HookPanel | 伏笔 |
| `#/timeline`、`#/timeline/:id` | Timeline / EventDetail | 时间轴 |
| `#/references`、`#/references/:id` | ReferenceList / ReferenceDetail | 参考资料 |
| `#/trash` | Trash | 回收站 |
| `#/settings` | Settings | 左栏底部入口 |

- 路由解析按段数区分：2 段 → 列表、3 段 → 详情；type 缺省回退 `character`；未知首段回退 `#/`（不污染历史）。
- `#/chat` 与 `#/canvas` 独立页均已移除（聊天常驻右栏；画布 UI 删除、`plot_edge` 数据能力保留）。

## 3. 中栏结构

- **信息条**（自左向右）：项目名（点击回 `#/`；加载中「加载中…」；无项目显示「书架」）|「当前位置: 标题」（null → 未设置；点击跳 `#/outline` 并定位该节点）|「语言: {language}」| 聊天开关（仅 <1024px）。
- **TabBar**：概览 / 大纲 / 实体关系 / 伏笔 / 时间轴 / 参考资料 / 回收站 七个 tab；当前 tab 由路由首段驱动。
- **内容区**：按路由渲染；页面由「数据编排 + 区块」构成（区块 = 标题 + 内容；区块失败不阻塞其他区块，带重试）。
- **无项目引导**：Dashboard 引导形态——创建书 / 打开路径 / 导入备份入口。

## 4. 右栏 ChatPanel 结构（自上而下）

1. **会话标题行**：当前会话下拉切换（列出本项目会话：摘要 + 条数 + 相对时间；无历史提示；刷新/打开项目自动激活最近会话）+ 新会话按钮。
2. **断连横幅 / 错误条**：横幅「上次会话已取消」+ 重新发送 + 关闭；错误条 = 图标 + 文案 + 关闭。
3. **消息流**：user 消息右对齐气泡；assistant 消息无气泡纯排版（聊天正文衬线排版，见代码）；工具调用折叠行（成功 ✓ / 失败 ✗，展开见 args 摘要）；提案卡（proposal 事件瞬态：类型中文标题 + preview JSON + 确认/拒绝；已确认/已拒绝/失效三态，失效后按钮禁用）。
4. **focus 小条**：「正在讨论：{类型} {id}」（MVP 不查实体名）+ 关闭；来自 InfoBar「问 AI」/ 右键菜单注入。
5. **输入区**：多行输入（Enter 发送 / Shift+Enter 换行，组合输入法不触发）；streaming 期间禁用 +「AI 思考中…」。

## 5. 概览页（Dashboard）形态

- **引导形态**（无项目）：标题「还没有书，先创建一本」+ 新建表单 + 「打开其他路径…」折叠次级操作 + 导入入口。
- **概览形态**（项目已打开）：「项目概览」标题 + 区块网格——创作要素计数四卡、大纲概览、最近会话。

## 6. 交互红线（跨页通用约定）

- **操作按钮禁止收进 `...`/更多菜单**：所有操作按钮一律直接展示，禁止 `MoreHorizontal`/`⋯` 二级展开（时间轴事件行、伏笔行、书架项目行重命名等）；下拉菜单仅保留「会话选择」等选择器场景，不作为操作按钮容器。**右键菜单例外**——右键菜单是「需要时出现」的上下文交互，不违反本红线。
- **文字型操作按钮须与普通文本视觉区分**（如边框/底色，具体样式归代码）；图标按钮不受此限。
- **Base UI 菜单契约**：`DropdownMenuLabel`（= `Menu.GroupLabel`）必须用 `DropdownMenuGroup` 包裹——裸放 `DropdownMenuContent` 内，菜单打开时抛 Base UI error #31（MenuGroupContext is missing），曾致点击会话标题下拉整页白屏（`3e877a1` 根因修复）；封装文件头部有红线注释。
- **确认对话框**：不可恢复操作（purge、物理删关系）必须二次确认并说明影响范围；软删与回收站还原直接执行，不弹确认。
- **软删成功**：跳回列表/大纲页 + 轻提示「已移入回收站，可随时还原」。
- **带上下文进聊天（不跳页）**：InfoBar 统一「问 AI」入口或右键菜单 → 写入 chat store focusContext（对应 POST /chat 请求体 `context` 字段）→ 右栏显示 focus 小条；MainPanel 路由切换时清空 focus 上报（页面焦点上报见 §2 与代码）。
- **行级交互模式**（树/组 + 行结构页面统一心智，行级操作按钮收敛为只保留删除）：
  - 双击行 = 跳详情；单击标题 = 行内编辑（Enter 确认、Esc 取消、失焦保存）；选中节点 Enter = 就地新建子级；行级只保留删除按钮；拖拽排序/移动保留（层级约束与防环校验沿用各页语义）。
- **右键菜单**（大纲节点/实体/伏笔/参考资料/时间点/事件行）：菜单项 = 「注入会话上下文」+「建立关联」（新建 relation_records 关联，端点按行实体类型预填）；InfoBar「问 AI」统一入口保留。
- **主题切换**：左栏底部按钮（手动双主题浅/深；深色显示「浅色模式」，浅色显示「深色模式」）。
