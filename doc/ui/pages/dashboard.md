# Dashboard 首页原型

## 路由与数据

- 路由：`#/`（默认落地页）
- **两种形态（S1.5 修订）**：
  - **书架形态（无项目打开，loadError=NO_PROJECT_OPEN）**：创作根（启动目录）无 project.json 时进入书架——书籍列表 + 新建书籍 + 打开其他路径；数据 `GET /api/v1/project/list` → `{ rootPath, books: [{ name, path, updatedAt }] }`（服务端扫描 `创作根/books/` 下含 project.json 的子目录）
  - **概览形态（项目已打开）**：以下数据（并行请求，全部失败不阻塞页面渲染）：

| 用途 | 端点 |
|------|------|
| 项目信息 | `GET /api/v1/project/config` |
| 四类要素统计 | `GET /api/v1/entity/character`、`/setting`、`/location`、`/hook`（各取 `total`，limit=1 即可） |
| 大纲概览 | `GET /api/v1/outline`（递归统计卷/章/场景数） |
| 最近会话 | `GET /api/v1/chat/sessions`（取前 5 条） |

## 书架形态（S1.5 新增；S1.6 显示方案修订：卡片网格 + 封面占位）

> 形态判定：`config === null && !configLoading`（loadError=NO_PROJECT_OPEN 或网络失败）。
> 数据 `GET /api/v1/project/list` → `{ rootPath, books: [{ name, path, updatedAt }] }`（按 updatedAt 倒序）。

### 布局线框

```
┌───────────────────────────────────────────────────────────────┐
│ 书架                               创作根: ~/novels            │
├───────────────────────────────────────────────────────────────┤
│ ┌────────────┐ ┌────────────┐ ┌────────────┐                   │
│ │  我的小说   │ │  修仙：…   │ │  长安夜雨   │   卡片网格          │
│ │ ▓ 封面占位  │ │ ▓ 封面占位 │ │ ▓ 封面占位  │   (2/3/4 列响应式)  │
│ │  2026-08-01│ │  2026-07-30│ │  2026-07-28│                   │
│ └────────────┘ └────────────┘ └────────────┘                   │
│                                                               │
│ 新建书籍                                                       │
│   书名: [________________________]  [新建]                     │
│   （创建于 创作根/books/<书名>/）                                │
│ [打开其他路径…]（折叠：路径输入 + 打开，S1.4 保留）                │
└───────────────────────────────────────────────────────────────┘
```

- 页面分三区：**标题区**（大标题「书架」+ 右侧创作根路径次级灰字，`bookshelf.rootPath`）、**列表区**（卡片网格）、**操作区**（新建表单 + 折叠的打开其他路径）。
- 网格响应式：`grid-cols-2 sm:grid-cols-3 lg:grid-cols-4`，卡片宽度自适应；书少时左对齐不拉伸（`auto-fit` 亦可，实现期定）。

### 信息层级

| 展示 | 数据来源 | 状态 |
|------|---------|------|
| 封面占位：渐变底色块（aspect 4:3）+ 书名首字居中 | **前端派生**：书名 hash → HSL 色相（同书同色、稳定），无任何数据依赖 | 可立即实施 |
| 书名（卡片主标题，超长截断） | `books[].name` | 现有 |
| 更新时间 | `books[].updatedAt`（ISO → `YYYY-MM-DD HH:mm`，formatTimestamp） | 现有 |
| 章节数 / 大纲进度条（卡片副行） | 无——list 未返回；需 open 后 `GET /outline` 递归统计或未来 list 扩展字段 | 未来扩展 |
| 字数（卡片副行） | 无端点（正文不落库，AI 不代笔） | 未来扩展 |
| 最近位置（「读到：第3章·灵根测试」） | 无——list 未返回 current_position 及标题映射 | 未来扩展 |
| 自定义封面图 | 无数据源；若未来支持 `books/<书名>/cover.png` 再议 | 未来扩展 |

设计取舍：**卡片网格而非列表**——书架隐喻成立、无封面图数据源时用「封面占位」抽象（不依赖后端）、为未来扩展留副行位置、整卡可点 = 大点击目标。纯 Tailwind 实现，无新依赖，不算高保真美化。

### 关键交互

- **打开**：整卡可点（卡片即按钮）→ `openProjectAt(path)` → 刷新 config/outline；rebuilt 时 toast（决策 13）。hover 态：卡片提亮 + 「打开」提示浮现（或右上角出现打开按钮）。
- **新建**：表单在网格下方；**空态时表单上升为页面主操作**（引导卡内）。书名去首尾空白、非空校验（内联提示）；成功 → `loadBookshelf` 刷新列表 + 打开新书（现状不变）。
- **打开其他路径**：保留 S1.4 折叠区（绝对路径 → `POST /project/open`）。
- **排序**：现状服务端按 `updatedAt` 倒序。前端排序切换（最近更新 / 书名 A-Z）纯前端可实现，**MVP 可选**，不强制。
- **刷新**：MVP 可选（错误态已有重试）；如做，放标题区右侧小按钮。
- **删除 / 重命名**：后端无端点 → **未来扩展**。设计预留：卡片 hover 右上角「⋯」菜单位（重命名 / 删除 / 在文件管理器显示），MVP 不实现菜单。删除书 = 删目录（含三文件），未来需谨慎设计（二次确认 + 说明影响范围，见 layout.md §3.2）。

### 状态

| 状态 | 呈现 |
|------|------|
| 加载中（首次） | 网格骨架：4 张静态占位卡（灰底块，无文字闪烁） |
| list 加载失败 | 页面级错误横幅：网络失败 →「无法连接服务…」；其他 →「书架加载失败」；均附 [重试] |
| 空态 | 引导卡：「还没有书，先创建一本」+ 新建表单突出 + 「打开其他路径」次级操作 |
| 有书 | 卡片网格 + 底部新建表单 |
| 打开/新建失败 | 网格上方错误横幅（describeOpenError 映射：INVALID_PROJECT_PATH / PROJECT_ALREADY_EXISTS 等），不藏在折叠区 |

### 与 AppShell / 全局布局的关系

- 书架形态下顶栏项目名显示「**未打开项目**」→ 建议改为「**书架**」（无项目时所在即书架，语义更准；layout.md §2.1 同步）。侧栏 7 项照常显示，无项目时点击进入各页错误态（现状行为，MVP 接受，不处理）。
- **回到书架入口（实现缺口）**：store 已有 `closeProject`（POST /project/close）但 UI 无入口——打开书后无法返回书架。方案：概览形态页头加「回到书架」按钮（closeProject → 回 `#/` 重新进入书架形态，Dashboard 按 config=null 自动 loadBookshelf）。放 Dashboard 概览形态内，不动 AppShell 顶栏。
- 书架形态不渲染概览区块；`#/` 下其他路由（设置等）在无项目时照常可达（设置页与项目无关，合理）。

### 未来扩展（不实现，backlog 候选）

- list 返回每本书统计（章节数 / 大纲进度 / 字数 / 最近位置）→ 卡片副行 + 进度条
- 真实活跃时间：**`updatedAt` 语义偏差**——project.json 的 `updated_at` 仅在创建与 `PUT /project/config` 时刷新，outline 保存、实体/Delta/对话写入都不更新，书架排序无法反映真实活跃度。MVP 接受现状（排序 = 配置更新时间）；未来由 list 服务端计算活跃时间（max(project.updated_at, outline 树最大 updated_at, data.db 最新 updated_at)），需服务端配合
- 删除 / 重命名书籍端点 + 卡片「⋯」菜单
- 分组展示（最近更新 / 更早）

## 信息层级

| 区块 | 展示 | API 字段 |
|------|------|---------|
| 项目信息 | 名称、语言、当前位置、提示词（截断 2 行） | `name` / `language` / `currentPosition` / `prompt` |
| 创作要素 | 四张计数卡（数字 + 类型名） | `GET /entity/:type` → `total` |
| 大纲概览 | 卷/章/场景计数、最近更新 | `GET /outline` → `children` 递归统计（无现成汇总字段，前端自算）；最近更新 = 树中最大 `updatedAt` |
| 最近会话 | 摘要、消息数、相对时间 | `sessions[].{ lastMessage, messageCount, updatedAt }` |

## 关键交互状态

- **空态（新项目）**：整页引导卡「项目还是空的」→ 主按钮 [先搭大纲]（跳 `#/outline`）、次按钮 [和 AI 聊聊设定]（跳 `#/chat`）；各区块显示对应空文案（「还没有会话」等）。
- **回到书架**：页头右上角 [回到书架]（`closeProject` → 回 `#/`，书架形态）。这是概览 ↔ 书架切换的唯一入口（实现缺口，S1.6 补齐）。
- **加载态**：各区块骨架。
- **错误态**：单区块失败 → 区块内「加载失败 [重试]」；全量失败 → 全局错误横幅。本页理论上不会出现业务错误码（项目已打开）。
- **操作流**：点会话行 → 跳 `#/chat` 并恢复该会话（chat store 注入 `session_id`）；点统计卡 → 跳 `#/entities/:type`；点「去大纲」→ `#/outline` 并定位当前位置节点。
